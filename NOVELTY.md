# Concept separation record

LoopForge addresses industrial symbiosis: a closed ring of factories exchanging
declared material quantities, with scarce stock and input capacity, simultaneous
consent, delivery-dependent performance bonds, and reusable receiving receipts.

Dependency Sentinel addressed software security advisories, immutable version
dependency graphs, transitive publication permission, and scoped security
exceptions. LoopForge has no software-package registry, OSV notice, release
channel, publication gate, or vulnerable-version mitigation permission.

The distinction is structural:

| Dimension | LoopForge |
| --- | --- |
| Domain | Industrial circular-material exchange |
| Users | Suppliers and processing factories acting as counterparties |
| Intelligence | Interpret material/process fit and receiving evidence |
| Coordination | Closed multi-owner barter cycle |
| Scarcity | Exact available grams and receiving capacity |
| Economic mechanism | Equal outgoing-leg performance bonds and receiver compensation |
| Core lifecycle | Propose → review → ratify → reserve → dispatch → adjudicate → clear → reuse |
| Durable state | Conservation ledgers, reservations, challenged delivery history, material receipts |
| Information surface | Contract records and operator scripts; no interface reservation |
| Documentation thesis | Simultaneous commitments, transport exceptions, and conserved ledgers |

The baseline included all 19 existing Season 3 history entries and the local
main-account projects. Those cover funding, data permissions, agreements,
environmental sensors, workforce scheduling, financial pools, civic works,
recalls, credentials, treasury mandates, coverage, and work grading. None
implements atomic circular-material inventory clearing and receipt-derived
reissue under per-leg bonded delivery consensus.

Rejected alternative directions included scientific evidence graphs,
translation reconciliation, humanitarian dispatch, and qualification exchange:
their proposed mechanisms overlapped prior registry/review, agreement,
incident, or credential workflows more heavily.

The concept was reserved in the shared history before the project directory was
created. Visual styles, layout skeletons, and screenshot archives were not
consumed because the user requested contracts only. A rich implementation is
not a guarantee of external submission acceptance; no official approval is
claimed.
